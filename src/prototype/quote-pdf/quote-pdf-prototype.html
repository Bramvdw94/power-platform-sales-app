Example Quote Q-00012, revision 1, for Fabrikam Logistiek B.V. Every name and amount is sample data. The sheet stays white in dark mode because it is the printed document.

Layout

Recommended: Send opens one dialog with two ways to deliver
  • Default: email the PDF from the user's own mailbox through the Office 365 Outlook connector. It lands in their Sent Items, so replies come back to them.
  • Alternative: download the PDF and send it yourself (another mail client, a portal, a printed copy).
  • Both lock the Quote, set it to Sent, record the sent date and store the exact PDF on the Quote.
  • This is a one-off send, not Outlook integration: no email activity is tracked, so the "no Outlook" scope line still holds.

Recommended: the Quote page shows what was sent, to whom, and the exact PDF
  • A copy of the sent PDF is stored on the Quote, so it never changes later, even when prices or company details do.
  • "Sent" line: date, who sent it, how (Outlook or download) and to which address.
  • Actions on a Sent Quote: Accept, Reject, Revise. Download PDF always returns the stored copy.
  • A Draft has "Preview PDF" only, with a DRAFT watermark and no stored copy.

Recommended: one Quote settings record, edited in the app by the Catalogue Manager
  • Kept in a one-row Dataverse table, shown as a "Quote settings" tab on the Products page. SalesApp Catalogue Manager edits it (Megan in the demo); everyone in sales reads it.
  • Not environment variables: those need a maker in the Power Platform portal, and managers should change terms or the logo without one.
  • The PDF reads these settings at the moment it is made, and the stored copy freezes them.

Proposed: a block-based template builder, like the Process builder's outline
  • A template is an ordered list of fixed blocks, built by drag and drop on the A4 page itself: drag a block from the tray onto the page, drag blocks up and down on the page, drag one back to the tray to remove it. Click a block to edit its options and texts. Move up, Move down and Remove buttons do the same from the keyboard.
  • Page style per template: accent colour, typeface, logo position. Company details, logo and default terms still come from Quote settings.
  • Three starter templates: Business letter (Default), Proposal and Order form; managers can copy, change or add more. A Quote uses the Default unless the user picks another while it is a Draft.
  • Templates are edited by the SalesApp Catalogue Manager (a separate role is an option). Sent Quotes keep their stored PDF, so editing a template never changes what a customer received.
  • Saved as JSON in a Dataverse row, the same way Process definitions are stored, so the browser renderer can draw it.
