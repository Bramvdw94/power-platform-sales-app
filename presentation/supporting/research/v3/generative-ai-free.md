# Generative AI the app can use for free or very cheaply, without an Azure subscription (research for issue #135)

Researched 2026-10-13. Sources are Microsoft Learn and Microsoft licensing pages, Google's Gemini API terms, and Mistral's own docs and help centre, all cited inline. Context: the code app (React + Vite + TypeScript) on the plain Dataverse environment `dev-salesapp`, a Microsoft 365 developer tenant with no Azure subscription and no credit card, and Power Apps Premium for users. What the AI has to write: a summary of an Account's or Opportunity's Activities (timeline summary), a follow-up email draft after a Phone Call or meeting, and a suggested Next step for an open Opportunity.

## Answer

- **Nothing in the tenant gives lasting free generative AI.** Copilot Studio, the Work IQ connector and AI Builder prompts all run on **Copilot Credits**. You buy those as a prepaid pack or pay for them pay-as-you-go, and **pay-as-you-go needs an Azure subscription linked to the environment** ([Copilot Studio billing](https://learn.microsoft.com/en-us/microsoft-copilot-studio/requirements-messages-management)). The Microsoft 365 E5 developer sandbox doesn't include Microsoft 365 Copilot, and it doesn't include Azure credits either (see `research/v3/outlook-teams.md`).
- **The only included credits are the AI Builder credits that come with Power Apps Premium, and they are ending.** Power Apps Premium includes 500 AI Builder credits per user per month. "Seeded credits will be removed on November 1, 2026", which is less than three weeks away. Licences bought or renewed before then keep their credits until the end of the contract term, and new licences get none ([credit management](https://learn.microsoft.com/en-us/ai-builder/credit-management), [end of AI Builder credits](https://learn.microsoft.com/en-us/ai-builder/endofaibcredits)). So this is a short bonus at best, and only if Bram's Premium licences are paid licences that actually came with credits.
- **Recommendation: Mistral's API, called from a Dataverse plug-in behind one custom API, for example `vibe_GenerateText`.** Mistral is hosted in the EU by default ([Mistral data location](https://help.mistral.ai/en/articles/347629-where-do-you-store-my-data-or-my-organization-s-data)). Its free mode needs no credit card, only a verified phone number ([Experiment plan](https://help.mistral.ai/en/articles/450104-how-can-i-try-the-api-for-free-with-the-experiment-plan)). The paid tier works on prepaid credits held in a Mistral account, outside the tenant ([Mistral billing](https://docs.mistral.ai/admin/billing-usage/billing)). Mistral Small 4 costs $0.15 per million input tokens and $0.60 per million output tokens ([Mistral pricing](https://docs.mistral.ai/inference/pricing)). A timeline summary costs well under a tenth of a cent, so a €10 top-up covers thousands of them.
  - **Use free mode for development, with test data only.** Requests on the free plan "may be used to train Mistral's models". Move to €10 of prepaid credit before any real customer data goes through it.
  - **Keep the provider behind the custom API**, so it can be swapped later (for AI Builder prompts, OpenAI or Anthropic) without changing the code app.
- **Not recommended:** Copilot Studio agents (needs Copilot Credits, and the trial can't publish), Work IQ (billed in Copilot Credits, and it searches Microsoft 365 content rather than writing from Dataverse rows), Copilot in Power Apps (works for model-driven and canvas apps, not in a code app's UI), and the free tier of Google's Gemini API (its terms forbid user-facing apps for users in the EEA on the free tier).

## 3. How the recommended route works

1. **Custom API `vibe_GenerateText`**, synchronous, with inputs such as `Kind` (Summary, FollowUpEmail or NextStep) and `RegardingId`, and output `Text`. The code app adds it with `pa app add dataverse-api` and calls it as a typed service ([actions and functions in code apps](https://learn.microsoft.com/en-us/power-apps/developer/code-apps/how-to/add-dataverse-action-function), and `research/code-apps-dataverse.md`). This sits next to the process engine plug-in from ADR 0001 and doesn't change it. It can be a second plug-in class in the same plug-in package.
2. **The plug-in builds the prompt on the server.** It reads the Opportunity, its Activities (Notes, Tasks, Phone Calls) and the Account, keeps only what the caller is allowed to read, and sends one chat request to Mistral.
   - Plug-ins may call HTTPS hosts by DNS name. Use `HttpClient` with a timeout, and turn off KeepAlive ([access web services](https://learn.microsoft.com/en-us/power-apps/developer/data-platform/access-web-services)).
   - Set a timeout of about 30 seconds, well inside the plug-in's 2-minute limit.
3. **The API key can't go in a secret environment variable**, because that type needs Azure Key Vault and an Azure subscription ([Key Vault secrets](https://learn.microsoft.com/en-us/power-apps/maker/data-platform/environmentvariables-azure-key-vault-secrets)). Store it instead in a `vibe_` settings row whose key column has **column security**, so only System Administrators can read it, and have the plug-in read it as the system. A custom API plug-in has no step, so the step's secure configuration isn't available.
4. **The app only shows a draft.** Summaries and email drafts appear for the Owner to edit and send. A suggested Next step fills the field for the Owner to accept. Nothing is saved without the user.
5. **Cost control:** set a monthly cap in Mistral, don't top up automatically, and in the plug-in limit how many Activities go into the prompt (for example the last 30) so requests stay small.

## Open points

- **Are Bram's Power Apps Premium licences paid, and do they show seeded AI Builder credits?** Check in the Power Platform admin center under Licensing > Capacity add-ons. If they do, AI Builder prompts through a flow are free until the contract term ends, and can be a second provider behind `vibe_GenerateText`.
- **Mistral free-mode rate limits** aren't published as numbers. Measure them in Mistral's console. The training clause means free mode is only for test data.
- **Calling an AI Builder prompt directly from a plug-in** (without a flow) wasn't verified.
- **Legal note:** sending customer data to Mistral makes Mistral a processor. Its DPA and EU hosting cover the usual GDPR needs, but the team should agree to it before production.
- **Language:** prompts should ask for Dutch or English to match the team. Mistral models handle both. Check output quality on a few real Opportunities before choosing Small 4 over Medium 3.5.
