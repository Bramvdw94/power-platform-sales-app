# Supporting content

Copies of the working notes the talk draws on. All were written by Claude during the project and are kept here for reference.

- `research/`: research findings per version (code apps, Dataverse security, activities; `v2/` and `v3/` for the later versions, including Jev and generative AI).
- `agent-skills-setup/drafts.md`: draft agent-skills configuration (issue tracker, triage labels, domain docs).
- `ci/ci.yml`: the CI workflow draft.
